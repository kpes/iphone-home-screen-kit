# Security

This skill runs with Full Disk Access on your Mac and writes to your iPhone over USB. If you find a
way it could expose data, damage a layout without a restore point, or run something it shouldn't,
please report it privately with GitHub's **Report a vulnerability** button (Security tab), not as a
public issue. It's a hobby project, so replies may be slow, but security reports come first.

Not a vulnerability: Apple changing an undocumented interface in a new iOS version. Please report
that with the iOS compatibility issue template.
